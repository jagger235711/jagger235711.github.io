**新鑫考场科目三考试起步流程**

**一、 上车前准备**

1. 安全员处：在副驾驶侧等待，向安全员出示身份证。
2. 绕车检查：听到“开始考试”指令后，逆时针绕车一周。
3. 感应按钮：在右后方和左前方分别按下感应按钮（每个按1-3秒，可多按几次）。
4. 准备上车：完成绕车检查后，从驾驶位侧上车。

**二、 上车后操作**

1. 检查灯光：上车后，拨动远近光交替灯光，检查灯光是否复位。
2. 调整座椅：调整驾驶座椅靠背至舒适位置。
3. 系安全带：确保正确系好安全带。

**三、 启动与人脸识别**

1. 启动车辆：踩下离合器和刹车，然后启动发动机。
2. 人脸识别：车辆启动后进行人脸识别，等待验证成功。
3. 灯光考试：人脸识别成功后开始灯光考试，请按照语音指令操作。考试结束后，关闭所有灯光。
4. 等待指令：完成灯光考试并关闭所有灯光后，等待起步指令。

**四、 起步（五个步骤）**

听到起步指令后，请按以下步骤操作：

1. **打转向灯：** 打开左转向灯。

2. **转动方向盘：** 方向盘向左打大约半圈（约180°）。

3. **观察确认：** 通过左右后视镜和窗外仔细观察，确认周围交通安全。

4. **松手刹：** 确认安全后，踩住离合器和刹车，松开手刹。

5. 挂档起步：

    挂入一档。

   - **注意：** 挂入一档后开始计时，必须在10秒内成功起步，否则扣10分。

**五、 停车后操作（五个步骤）**

考试过程中停车后，请按以下步骤操作：

1. **回空挡：** 将变速杆推回空挡位置。

2. **拉手刹：** 向上拉紧手刹。

3. **熄火：** 关闭发动机。

4. 解安全带下车：

    解开安全带，确认后方安全后开门下车。

   - **注意：** 下车时务必确保安全带没有被车门夹住带出车外，否则关不上车门将扣100分。

5. **关门等待：** 在车外将车门关好，然后走到副驾驶侧等待考试成绩播报。

**考试机会说明：**

- 考试共有两次机会。
- 如果第一次考试在绕车检查和灯光考试阶段合格，第二次补考时则无需重复进行这两项考试。
